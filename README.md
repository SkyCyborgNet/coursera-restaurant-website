# Module 3 Solution

This repository contains my solution for **Module 3 Coding Assignment** from the Coursera course:

HTML, CSS, and Javascript for Web Developers

## Project Description

This project implements a responsive web page using Bootstrap 3.

Features included:

- Responsive navbar
- Mobile hamburger menu
- Dropdown menu with:
  - Chicken
  - Beef
  - Sushi
- Centered page heading ("Our Menu")
- Responsive layout using Bootstrap Grid
- Single tall content section

## Technologies Used

- HTML5
- CSS3
- Bootstrap 3
- JavaScript
- jQuery
